## 2. The sets

### The fold — every cell `BC` was counted on

`v3/colab/v36_ironman_er.csv` — **600 cells** · 200 pairs · seeds 46/47/48

The whole iron-man-2 matrix, unsampled and unfiltered. A rate for `ER` is comparable to `BC`'s
only if it is the same cells, the same reference, the same canvas, the same eye and the same
page. Generated by `v3/build/make_v36_ironman_set.py`.

### The prompt comparison — both sides of the record

`v3/colab/v36_editset.csv` — **150 cells**, 29 fail, 121 ok · 112 pairs · seeds 46/47/48

The 29 cells the reviewer marked FAIL for `BC` in the blind sweep, plus 121 it left unmarked,
sampled `random.Random(46)` over the sorted remainder. **Both sides on purpose:** the failures
say what a longer prompt buys, the passes say what it costs, and only the second decides
whether it ships. Generated by `v3/build/make_v36_editset.py`.

### The `ER2` set — what currently fails

`v3/colab/v36_er2_set.csv` — **53 cells** · 32 pairs · seeds 46/47/48

The union of `BC` pass 2's failures and the `ER` sweep's. Selected on failure, so **nothing
measured on it is a rate** — it can only show whether a shorter prompt reaches failures the
longer one does not. Generated by `v3/build/make_v36_er2_set.py`.

### The transformer probe — cells with a known verdict

`v3/colab/v36_fp8_set.csv` — **74 cells**, 40 both_clean, 18 er_fail, 16 er_repaired · 58 pairs · seeds 46/47/48

Drawn from the classification rather than sampled: every cell `ER` failed, every cell it
repaired over `BC`, and a fixed-seed sample of cells both arms pass. The last group is the one
that decides whether a weights swap is safe. Generated by `v3/build/make_v36_fp8_set.py`.

## 3. The review protocol

Six marking passes were made, and they are not equally strong. Stated in the order they were
run, with what each can and cannot carry.

| pass | what it asks | blind? | complete over? |
|---|---|---|---|
| `bc_count` / `er_count` | one button per cell, does it fail | to the other arm | all 600, each arm |
| `v36_er_vs_bc` | which of the two would you ship | no | the 150-cell set |
| `bc2_count` | the `BC` re-mark | to the first pass | all 600 |
| `v36_discordant` | which of these two | **yes** — arm hidden, sides shuffled, fixed seed | the 25 disagreements |
| `v36_bcfail` | does `ER` have the same problem | no — `BC` left, `ER` right | all 50 `BC` pass-2 failures |
| `v36_fp8` | did the outcome change | no | the 74-cell probe |

**No counting page carries a prior verdict**, in the page or its source: a rate is worth
something only if the pass did not know the answer while it was being made.

**The protocol's own failure mode is in the record.** The same 600 `BC` cells marked twice by
the same reviewer gave 29 failures then 50 — cell agreement 94.8%, but Jaccard 0.44 on
failures. That swing is larger than the difference the first comparison claimed between two
arms, which is why every surviving claim is paired.
