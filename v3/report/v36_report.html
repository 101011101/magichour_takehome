ER — one verb in call 2

The deployed pipeline changes by one verb. BC_klein's call 2 says dress the person in the clothing shown in image 2; ER says replace the clothing in image 1 with the clothing in image 2. Nothing else moves — same reference, same canvas, same seed, same model, same call count. The architecture and the reasoning are on the long read; this page is the result.

With the seed randomiser

A rejected image is redrawn at a fresh seed rather than repaired. Measured on the sweep itself — every pair was run at three seeds, so the record says what a retry would have done.

ER does not only fail less, its failures are less seed-stable — so the retry lands more often on top of a smaller starting rate. One retry costs about 3% more calls, because only rejects are redrawn. Why this is not 97%, and what it would take.

What one word repairs

The failure class is the same every time: the wearer's own clothing survives underneath the new garment. Dress the person in names only the putting-on; replace…with names the removal too.
