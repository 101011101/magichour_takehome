Failure gate — simulated cascade

Every arm graded, nothing assumed. Move the threshold and the pipeline re-simulates.
No generations were made for this page. Each arm already has an output and a human verdict; the gate scores them, and the cascade is replayed at whatever acceptance threshold you choose.
  • Green = the gate accepted and the cascade stopped. Red = rejected, escalate. Faded = never reached
  • Each cell shows the composite score, the weakest check that produced it, all five sub-scores, and what the human called that frame — so gate and reviewer can be compared directly
  • The composite is the weakest check, not the average: one hard failure should sink a frame rather than being hidden by four good scores
  • The garment check is deliberately absent. §2b measured garment_sim at 0.78 and a VLM at 4/5 on an output that transferred no garment — both reward a plausible garment over the correct one, so neither can carry this. What the gate does catch: degenerate frames, no-ops, duplicated people, identity leaks, repainted backgrounds
  • The header shows units per request at the current threshold and what the human called the frame the gate accepted — that second number is the one that matters
