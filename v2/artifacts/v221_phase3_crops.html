2 — PRE: repair the raw photo, then crop normally
  • A different architecture, not another arm. AC crops and then fills the damage; PRE repairs the raw frame so the damage is never created
  • PRE1 LaMa over the hair region, no prompt · PRE2 klein and PRE3 Qwen, both prompted “make this person completely bald”
  • All three then run the unchanged cropper, so the only variable is the raw image it receives. Each caption reports what the head cut took and how much fringe survived — compare against PRE0
  • The prediction, recorded before the run: PRE should beat AC because filling a white hole in a crop is out of distribution with no context, while hair removal on a whole portrait is a routine edit with the entire body as context. PRE1 vs AC6 is the clean test — same LaMa weights, different position in the pipeline
