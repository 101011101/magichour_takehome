One variable per set — the garment reference. BASE against C2 (background white, wearer kept), C3.1 (face and hair removed), C3.2 (hair kept) and C4 (clothes only). Split by pair kind: duo pairs, where the reference is a whole person, against product pairs that were already clean flat-lays.

Person-to-person transfer
v221_duo_transfer.html · build: make_combo_page.py
Taking one person's outfit and putting it on another. The metric that matters is identity attribution: the result should look like the base person wearing the source person's outfit. A face closer to the source means klein imported the wrong identity — failure mode F1, the one cropping is meant to make structurally impossible.
