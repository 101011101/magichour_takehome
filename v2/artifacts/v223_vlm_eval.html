VLM gate evaluation — Qwen/Qwen3-VL-8B-Instruct

Can an open-weights VLM do the job the deterministic gate could not?
Five prompts × 114 human-tiered outputs, 4-bit on a free T4. The gate's job: fire when a frame is not perfect, so the harness escalates to QX. The bar is the accept-everything baseline (62.3%) — the deterministic gate never beat it (AUC 0.506).

Only PERFECT ships — can the rule be applied?

Only PERFECT ships; OK escalates. The obstacle is the model's own vocabulary — three of the five prompts never once said PERFECT, so for them the rule means escalate everything.

Tie-break by independent score, not pairwise

Score each candidate independently — count the prompts that did not say FAIL — then take the higher. Because neither image is shown beside the other, there is no position for the model to be biased by, which is what sank the pairwise call.

Avoids the already-failed arm on 4/5, against 3/5 for the pairwise call. But always taking QX scores 5/5 here, so on this evidence the trivial rule still wins — n = 5.

The artefact prompt never fired once — it answered CLEAN on all 114 outputs, including every frame you marked fail. Asking a VLM to spot AI artefacts does not work here, because these failures are not artefacts: the images are competent photographs of the wrong thing. usable and tryon are barely better, firing 2–4 times in 114 and changing the production outcome not at all.
Only garment works, and only because it sees the reference image. 70.2% against a 62.3% baseline, catching 53% of failures. In production it takes 5 shipped failures down to 2, at 1.737 generations against the oracle's 1.526 — and it beats flat BC_klein (2.000 generations, 4 failures) on both axes. The lesson is that VLM-A needs the garment reference as input, not just the output.
VLM-B is dropped. Pairwise selection agreed with itself on only 13/38 (34%) of pairs when the two images were swapped — worse than chance, so it reads position rather than content. On the 5 pairs that actually escalate it picked the arm that had already failed 2 times. Always taking QX scores perfectly on the same set.
Caveat before this is treated as settled: the model hedges heavily — 331 of 570 verdicts are OK, only 49 are FAIL. A binary forced choice with no middle option, and fp16 instead of 4-bit, are both untried and both plausibly worth several points. This measures Qwen3-VL-8B at 4-bit with these five prompts, not "open VLMs".
